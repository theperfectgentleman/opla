# Arena rubric: analysis domain sketch

Score each candidate 1-5 per criterion. Recommend one base. Name grafts worth taking from losers. Do not average shapes.

1. **Table is not a Form.** Capture may have formId. Derived/upload/view cannot. Snapshot-as-LIVE-form is a fail.
2. **One executable query.** Builder save and dashboard re-run are the same AST. A chart cannot store a souvenir aggregation. Rows vs summary should not be one mushy object if that lets illegal states through.
3. **Viz contract.** table, chart, map, kpi. Map needs live geo. Walker is scratchpad, not persisted viz. Markdown is a board tile, not a fake question, unless justified.
4. **Nav split.** Analysis is project explore. Reports is org share with team grants, server-backed. No fourth noun. No localStorage.
5. **Interface depth.** Small public surface that hides compile, parse, pin limits, formula. Callers should not orchestrate four tools.
6. **Migration.** parse v1 or reject with a code. No dual-write of two query languages.
